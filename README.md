# Chai & Chill POS — Tea Shop Billing System

A vibrant, lightweight Point of Sale web application designed for tea stalls and cafes to manage orders, billing, and sales analytics.

## Features

- Tea shop menu catalog (Chai varieties, Coffee, Snacks, Coolers) with one-tap order addition
- Order management cart supporting custom item quantities and notes
- Dynamic bill calculation including discounts and GST tax computation
- Register lock and unlock mechanism for cashier shift security
- Sales report export supporting JSON and CSV downloads for accounting
- Local storage persistence keeping product lists and transaction history safe offline

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Tailwind CSS
- Font Awesome
- LocalStorage API

## Installation & Setup

This is a standalone, client-side web application. No complex build pipelines, database configurations, or package installations are required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SSManikandaprabu/Chai-Chill-.git
   cd Chai-Chill-
   ```

2. **Run the application:**
   - **Direct Browser Launch**: Double-click `chai & chill.html` to open it directly in any modern web browser (Chrome, Firefox, Safari, Edge).
   - **Or via Local HTTP Server**:
     ```bash
     python -m http.server 8000
     ```
     Then open [http://localhost:8000/chai & chill.html](http://localhost:8000/chai & chill.html) in your browser.

## Usage

1. Launch the application in your browser following the setup instructions above.
2. Interact with the application controls and input fields tailored for Chai & Chill POS — Tea Shop Billing System.
3. Preferences and data are stored locally in your browser's LocalStorage where applicable.
